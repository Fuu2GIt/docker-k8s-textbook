    手を動かす教科書

    DockerとKubernetesの教科書

    この教科書は、コマンドラインをほぼ初めて使う人に向けて書いてあります。最初の読者は、就職でクラウドの仕事を目指す楓真さんです。ほかの初学者も、同じ手順で進められます。

    Linux、ネットワーク、IPアドレスは、知っている前提にしません。必要な言葉は、その場で一文で説明します。

    この教科書でできるようになること

    読み終えると、次の3つを自分でできるようになります。

    • 自作のWebアプリをDockerイメージにして、コンテナとして動かせる
    • Webアプリとデータベースを、Docker Composeでまとめて動かせる
    • ローカルのKubernetesでアプリを複数台動かし、更新と、障害からの復旧を試せる

    読み方

    上から順に進めてください。各章の終わりで、その章が作ったコンテナは消します。次の章は、その状態から始められます。残すものがあるときは、片付けの節に理由を書きます。

    Windows と Linux で手順が違うところだけ、タブで切り替えます。選んだ側は、このブラウザが覚えています。上の「Windows」「Linux」でも切り替えられます。

    コマンドのブロックには、行頭の $ を入れていません。「コピー」を押して、端末へ貼り付けてください。

    Windows では、断らない限り WSL2 の Ubuntu で実行します。その都度、実行場所を書きます。Linux では、Ubuntu の端末で実行します。

    「未確認」とある出力は、この教科書を書いた環境では実行できていません。見ていない出力を、見たように書くための印ではありません。実行できた出力だけが、出力欄に入っています。

    画面の進捗は、このブラウザの中だけに保存されます。サーバーへは送りません。
